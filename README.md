# For Knox

A one page birthday letter. Static site: HTML, CSS, vanilla JS.

## Publish on GitHub Pages
1. Create a new repository (any name).
2. Upload everything in this folder (index.html, style.css, script.js, assets/).
3. Settings > Pages > Source: Deploy from a branch > main / (root) > Save.
4. Your link appears after a minute at https://YOURNAME.github.io/REPO/

## Photo (optional)
Put a photo at assets/knox.jpg. It appears at the end of the letter. If the file is missing, nothing shows.

## Edit the message
Change the text inside the letter in index.html.
